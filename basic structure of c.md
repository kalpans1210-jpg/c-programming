No arguments and no return valueThe function neither receives data nor sends a result back.\#include <stdio.h>void add(void){&#x20;   int a = 10, b = 20;&#x20;   printf("%d", a + b);}int main(){&#x20;   add();&#x20;   return 0;}Here, add() has no arguments and returns nothing (void).2\. Arguments but no return valueThe function receives values, but it does not return a value.\#include <stdio.h>void add(int a, int b){&#x20;   printf("%d", a + b);}int main(){&#x20;   add(10, 20);&#x20;   return 0;}10 and 20 are passed to the function, but add() does not return anything.3\. No arguments but with return valueThe function doesn't receive any values, but it calculates and returns a value.\#include <stdio.h>int add(void){&#x20;   int a = 10, b = 20;&#x20;   return a + b;}int main(){&#x20;   int result = add();&#x20;   printf("%d", result);&#x20;   return 0;}add() takes no arguments, but returns 30.4\. Arguments and with return valueThe function receives values and also returns a value.\#include <stdio.h>int add(int a, int b){&#x20;   return a + b;}int main(){&#x20;   int result = add(10, 20);&#x20;   printf("%d", result);&#x20;   return 0;}Here, 10 and 20 are arguments, and the function returns 30.Easy way to rememberArguments = inputReturn value = outputSo:No input → No outputInput → No outputNo input → OutputInput → Output1. ## STRUCTURE:IT IS A USER DEFINED FUNCTION IN WHICH DATA TYPES STORES MULTIPLE VALUES OF DATA UNDER ONE VARIABLESYNTAX:&#x20;      STRUCT STRUCT\_NAME&#x20;      z{&#x20;       DATA \_TYPE VAR1;&#x20;       ...........VAR2;&#x20;       };## 2.union:A UNION IS A USER DEFINED DATA TYPES IN WHICH ALL MEMBERS SHARE THE SAME MEMORY LOCATIONWHAT IS UNION?A UNION LOOKS SIMILIAR TO A STRUCTUREUNION DATA&#x20;{&#x20;  INT A;&#x20;  FLOAT B;&#x20;  CHAR C;};THE MOST IMPORTANT CONCEPTd.a = 10d.b = 20the union member use the memory location.so when we put a value into d.b, it overwrites the data previously stored through d.atherefore, unlike a strength, we generally use one union member at a timeexample : find using tracing:The unions size is generally based on its largest member.for example, if:int = 4 bytesfloat = 4 byteschar = 1 bytewhen the union will typically 0ccupy 4 bytes.structure size vs union sizefor example :struct data{&#x20;  int a;&#x20;  float b;&#x20;  char c;};the structure needs storage for all members,plus any padding.the union only needs enough storage for its largest member,subject to alignment.
